# Baldi's Basics Challenges Demo — WebGL

Restored from the supplied Windows Mono release (Unity 2019.3.6f1), rebuilt with
Unity 2019.4.17f1. All seven original scenes are included, with the Grappling,
Speedy, and Stealthy challenges and their recovered C# gameplay, artwork and audio.

The supplied directory is labelled 1.1. Internal Windows settings are retained:
`Basically Games` / `Baldi's Basics Plus Challenge Demo`, version `0.1`.
The original title screen displays V1.1.

## Run

Double-click `start.bat` on Windows. Python 3 is required. Keep the server window
open while playing. Alternatively, serve this directory over HTTP and open
`index.html`; opening it directly with `file://` is unsupported. Reload once
with F5 if an older build was already open. Click the game to enable audio and
mouse capture. Use the original menus to choose a challenge.

WASD moves, the mouse turns, Shift runs, and Space looks behind. Left click or E
interacts; right click or Q uses the selected item. The mouse wheel or number
keys selects items. Escape pauses/resumes; Tab displays the map and M opens
the expanded map. Grapple intentionally disables walking: use its unlimited
grappling hook to move. Stealthy starts with chalk erasers.

The launcher uses local port 57323 so settings keep the same browser origin
between launches. A custom HTTP host or port has separate browser storage.

## Browser compatibility

All runtime files are local. Unity analytics and automatic reporting are disabled.
The canvas fills the window, with a black loading screen and one 240×3px bar.
Rewired uses its Unity input backend for browser keyboard and mouse. The original
managed libraries are retained to avoid property aliases generated by the
restoration tool. Windows-only XR and reporting plugins are excluded.
UI components are rebound to Unity's UI package. The menu cursor follows the
browser pointer in the original canvas coordinates.
Hidden pause canvases leave mouse capture to gameplay and restore menu input
when paused.

Native serialized settings for EnvironmentController, Map and LevelGenerator
are recovered separately: the restoration tool skipped these components because
they contain runtime multidimensional arrays. The three original tile grids
(1,561 / 2,775 / 729 tiles), map data, spawn positions and references are preserved.
The 5,178 TileController payloads omitted by the exporter are also restored from
the Windows binary, including positions, rooms, navigation flags and wall data.
Rebuilds validate all three scene grids, 170 door references and every NPC spawn
reference before compiling. Repeated prefab references are written explicitly
because Unity's YAML reader does not support the exporter's shared aliases.

Subtitle JSON is loaded from local Unity resources instead of reading a browser
URL as a filesystem path. Settings remain in the browser's persistent storage;
saves explicitly synchronize the filesystem. Quit stops the runtime, including pending game timers and render callbacks.

Custom material shaders and TextMesh Pro shader source are restored for WebGL.
The optional CRT post-process currently preserves the unfiltered image.
This is a recovered project, not the original development source. Rendering can
differ from the Windows release. Full completion and mobile/controllers have
not been tested.

## Verification

Browser checks cover normal menu selection, keyboard movement, mouse turning,
Speedy classroom doors, Stealthy chalk erasers and Principal movement, the
Grappling Hook, map display, pause/resume and audio output. Settings were also
checked across a page reload. No automatic external requests, WebSockets or
popups were observed. The original Windows files pass their SHA-256 inventory.

Mouse capture in a normal desktop browser could not be verified because the
desktop automation runtime failed to initialize. The browser test runner also
reports a frame scheduling advisory from the original frame limiter.

## Rebuild

`create/.work/Baldi's Basics Challenges Demo_1.1/` (`UnityProject/` contains the Unity project).
Run `build.ps1` with Unity 2019.4.17f1 and WebGL support. It builds in a temporary
directory and backs up an existing browser output before replacing files.

The original Windows release is unchanged. Original-file inventories, unmodified
exports, and pre-edit backups are in
